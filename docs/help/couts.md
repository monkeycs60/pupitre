# Coûts en tokens

La vue **Coûts** additionne les événements d'usage d'un projet pour le mois
choisi. Elle sépare les tokens du fil principal et ceux des sous-tâches, puis
ventile le total par modèle réellement observé dans les sessions.

L'**économie de délégation** compte les tokens exécutés par Luna qui n'ont pas
consommé le budget du modèle parent. C'est un contrefactuel en tokens : Pupitre
n'invente jamais un tarif en euros. Le modèle parent est celui actif au moment
de la délégation, même si le fil change de modèle plus tard.
