# Quotas

Pupitre lit les limites publiées par Claude Code et Codex CLI. Les jauges sont
des signaux : elles ne changent jamais automatiquement le modèle choisi.

Les fenêtres affichent le pourcentage utilisé lorsqu'il est disponible et leur
heure de remise à zéro. Les alertes natives peuvent signaler la dernière heure
d'une fenêtre ou un seuil d'usage. Une donnée absente reste « inconnue » ;
Pupitre ne devine pas un quota.
